# Mollen — Home Textile

Premium website template built with **Next.js (App Router)**, **React**, **Tailwind CSS** and **Framer Motion**.

- Sticky navbar, hero with CTA, services/products grid, features, testimonials/partners and footer
- Fully responsive: mobile, tablet and desktop
- Google Fonts + Unsplash imagery
- Vercel-ready (Root Directory: `13_home_textile`) for continuous deployment

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Live: https://13-home-textile.vercel.app
